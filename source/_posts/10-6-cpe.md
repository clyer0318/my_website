## 第一題：P1_uva10696 - f9

### 題意

題目要求我們判斷 n>=101, n<100兩種不同情況下的函數值

### 解題思路

經過觀察之後，發現任何小於100的數，結果出來都會是91

### 程式碼

```py
    while True:
    n = int(input())
    if n == 0:
        break

    if n <= 100:
        print(f"f91({n}) = 91")
    elif n >= 101:
        print(f"f91({n}) = {n - 10}")

   
```
